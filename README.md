# 坦克大战 · Tank Battle

一个纯 HTML5 Canvas 的单文件坦克大战游戏,无需任何依赖,双击 `index.html` 即可游玩。

## 玩法

- **移动**:方向键 `↑ ↓ ← →` 或 `W A S D`(手机端使用屏幕上的方向按钮)
- **射击**:`空格` / `J` / `Z`(手机端使用 FIRE 按钮)
- **开始 / 重新开始**:`Enter`
- **暂停**:`P`　　**静音**:`M`

## 规则

- 消灭所有敌方坦克即可过关,每关敌人会更多、更强
- 守住画面底部的**基地(★)**,基地被击中即游戏结束
- 击毁闪烁的奖励坦克会掉落道具:

| 道具 | 效果 |
|------|------|
| ⭐ | 火力升级(更快、更多子弹、可击穿钢板) |
| 🛡️ | 短暂无敌 |
| ❤️ | 生命 +1 |
| 💣 | 清屏炸弹 |
| ⏱️ | 冻结敌人 |
| ⛑️ | 基地护盾 |

## 地图图例

- 棕色砖墙 `B` — 可被子弹击毁
- 灰色钢板 `S` — 普通子弹无法击穿(满级火力可击穿)
- 蓝色水面 `W` — 坦克无法通过,子弹可越过
- 绿色草丛 `G` — 可通行并隐藏坦克

## 在线游玩

在 GitHub 仓库页面 **Settings → Pages → Source 选择 `main` 分支** 即可通过 GitHub Pages 在线游玩。

## 技术

- 单文件 `index.html`,原生 Canvas + Web Audio,无第三方库
- 分数最高记录保存在 `localStorage`
